# لاكاسا برجر — منيو رقمي (Static Website)

موقع منيو ثابت بالكامل (HTML5 + CSS3 + Vanilla JavaScript) بدون أي Backend أو قاعدة بيانات أو API خارجي.
الطلبات تُرسل مباشرة عبر رابط واتساب (`wa.me`).

## بنية المشروع

```
index.html      → الهيكل الرئيسي للصفحة
style.css       → التنسيقات (الألوان، البطاقات، الـ Bottom Sheets)
script.js       → كل المنطق: عرض المنتجات، السلة، الطلب عبر واتساب
menu.json       → بيانات المطعم والتصنيفات والمنتجات (عدّل هنا لإضافة/حذف/تعديل أي منتج)
config.js       → رقم الواتساب ورقم الهاتف ورابط الخرائط
assets/images/  → صور المنتجات (حالياً صور بديلة SVG — استبدلها بصور حقيقية بنفس الأسماء)
```

## كيف أغيّر رقم الواتساب؟

افتح `config.js` وعدّل:

```js
WHATSAPP_NUMBER: "9647811100884", // بالصيغة الدولية بدون + أو 00
```

## كيف أضيف صوراً حقيقية؟

ضع صور المنتجات داخل `assets/images/` بنفس الأسماء الموجودة في `menu.json`
(مثال: `pizza-lahm.svg` → استبدلها بـ `pizza-lahm.jpg` وعدّل المسار في `menu.json`).
يفضّل مقاس مربع (مثل 800×800) لأفضل نتيجة.

## كيف أضيف منتجاً جديداً؟

أضف عنصراً جديداً داخل مصفوفة `products` في `menu.json`:

```json
{
  "id": "unique-id",
  "category": "burger",
  "group": "اسم القسم الفرعي",
  "name": "اسم المنتج",
  "image": "assets/images/my-image.jpg",
  "price": 5000
}
```

أو مع خيارات (أحجام/أنواع):

```json
{
  "id": "unique-id",
  "category": "pizza",
  "group": "الايطالي",
  "name": "بيتزا جديدة",
  "image": "assets/images/new-pizza.jpg",
  "customizable": true,
  "optionsTitle": "الحجم",
  "options": [
    { "label": "صغير", "price": 6000 },
    { "label": "وسط", "price": 8000 },
    { "label": "كبير", "price": 13000 }
  ],
  "addonGroup": "burgerAddons"
}
```

## الرفع على GitHub Pages

1. أنشئ مستودع (Repository) جديد على GitHub.
2. ارفع كل ملفات هذا المجلد كما هي (بدون تعديل البنية).
3. من إعدادات المستودع → Pages → اختر Branch الرئيسي (main) والمجلد الجذر (/root).
4. الموقع سيعمل مباشرة بدون أي إعداد إضافي — لا يحتاج بناء (Build) أو تثبيت حزم.

## ملاحظات تقنية

- لا يوجد أي اتصال بقاعدة بيانات أو خادم خلفي؛ كل البيانات محلية في `menu.json`.
- السلة تُحفظ في `localStorage` في متصفح الزائر فقط.
- إرسال الطلب يفتح تطبيق واتساب مباشرة برسالة جاهزة تحتوي كل تفاصيل الطلب.
- التصميم متجاوب بالكامل (Mobile / Tablet / Desktop) ويدعم RTL بشكل كامل.
